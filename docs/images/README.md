# Recursos gráficos

Guardar aquí diagramas `.svg` y capturas sanitizadas `.png`/`.webp`. En Markdown: `![Arquitectura](../images/architecture.svg)`.

**No subir** capturas con tokens, claves, identificadores de cuenta, direcciones internas, datos personales ni nombres sensibles. Conservar originales fuera del repositorio; publicar solo versiones revisadas.

Las tablas de evidencia deben estar en `docs/experiments/` y los CSV verificables en `reports/comparison/`.
